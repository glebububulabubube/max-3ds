# MAX — мессенджер консоль-консоль для Nintendo 3DS

Крошечный клиент чата для 3DS (homebrew, Luma3DS) + Node.js-релейный сервер.
Консоль↔консоль: до 3 участников в одной комнате, общение через VPS-сервер
по TCP, ввод на кириллице через системную клавиатуру.

## Состав

- `source/main.c` — 3DS клиент (C, libctru, GUI на двух экранах)
- `server/server.js` — релейный сервер (Node.js, без зависимостей)
- `Makefile` — сборка по шаблону devkitPro
- `.github/workflows/build.yml` — сборка `.3dsx` в GitHub Actions

## Что умеет клиент

| Кнопка | Действие |
|--------|----------|
| **B**   | подключиться / отключиться от сервера |
| **A**   | написать сообщение (системная клавиатура, кириллица ОК) |
| **X**   | сменить комнату |
| **Y**   | сменить ник |
| **Start** | выйти |

- Верхний экран: комната, твой ник, события join/part.
- Нижний экран: лента сообщений.

## Развёртывание сервера

```bash
npm i   # не обязательно — зависимостей нет
node server/server.js          # по умолчанию порт 26662
PORT=9000 node server/server.js  # задать порт
```

Протокол построчный, фреймовый:
`NICK <имя>`, `JOIN <комната>`, `MSG <текст>`, `WHO`, `QUIT`.
Ответы: `#HELLO`, `#JOIN`, `#PART`, `#WHO`, `#ERR`, `M <ник>: <текст>`.

Впиши реальный адрес своего VPS в `source/main.c`:

```c
#define SERVER_HOST   "your.server.example.com"   // замени на свой хост/IP
#define SERVER_PORT   26662
```

> Важно: клиент идёт на 3DS без TLS — не гоняй критичный трафик, хост
> держи с firewall, закрытым портом от внешнего мира через `ufw`/iptables.

## Сборка клиента

**Вариант A — GitHub Actions (рекомендуется):**

1. Запуши репо на GitHub.
2. Workflow `build-3ds` соберёт `.3dsx` автоматически (контейнер `ghcr.io/devkitpro/devkitarm`).
3. Скачай артефакт из **Actions → последний запуск → max-3ds**.
4. Положи `Max.3dsx` в корень SD-карты 3DS, запусти через Homebrew Launcher.

**Вариант B — локально (нужен devkitPro):**

```bash
export DEVKITPRO=/opt/devkitpro
export DEVKITARM=${DEVKITPRO}/devkitARM
make
# на 3DS появится Max.3dsx
```

## Первый запуск обеих консолей

1. Подними сервер на VPS (см. выше).
2. Впиши адрес сервера в `main.c` и пересобери.
3. Установи `Max.3dsx` на обе 3DS.
4. Консоль 1: **B** (connect) → **Y** (ник) → **X** (комната, обе пишут одно и то же имя).
5. Консоль 2: то же самое с общей комнатой.
6. Общайтесь: **A** — сообщение.

## Ограничения и планы

- Без шифрования (TLS на 3DS неродной) — только хобби/локальная сеть.
- Нет истории на сервере — только live-чат в комнате.
- Нет сглаживания: сообщения приходят только пока сервер жив.
- Возможно позже: аудио-пуш нажатий, список файлов, раздельные комнаты с кодами.
